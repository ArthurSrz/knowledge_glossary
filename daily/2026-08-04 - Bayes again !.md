According [[bayes' theorem]] (bayesianism) which lies at the deepest root of [[knowledge]], the quality of [[knowledge]] is closely related to an equivalence. If given [[knowledge]], we can produce correct [[data]] then we can say its good [[knowledge]]. And to create such good [[knowledge]], we need to make it close to former [[data]]. 

Practically speaking, that means that, given some [[data]] here is [[knowledge]] is equivalent to given some [[knowledge]] here is some [[data]]. So to improve [[knowledge]] you have a double movement : 
1. given [[knowledge]] get some [[data]] ([[output]] here)
2. correct the [[output]] ("the expected [[output]] should be this")
3. given some [[data]] here is some [[knowledge]].
